# 采配採点

プロ野球の采配を、結果ではなく意思決定時点の勝利確率の変化で評価するための最小基盤です。

## 評価の考え方

各采配について、次の差分を採点します。

`実際の行動による勝率変化 - 代替案による勝率変化`

プラスならそのケースでは勝利確率を高める方向、マイナスなら代替案を採用した方が有利だった、という意味です。

**現状のモデル係数は動作確認用のベースラインで、採点結果はまだ信用できません。** 同点・走者なしの場面で打撃側の勝率を0.516と評価するなど、実データに置き換える前提の暫定値です。この歪みのせいで、スリーアウトを取られた直後の勝率が2アウトの局面より高く出るなど、**符号が逆になる場面があります。**実データで係数を推定するまで、採点結果を外部に出さないでください。

## データ

NPBを対象とし、データスタジアム株式会社の「授業・研究向けスポーツデータ」を取得元の本命としています。同社は[NPBエンタープライズと販売権利許諾契約を締結](https://datastadium.co.jp/news/LeO_0rMd)した正規の再販元です。

公開されている仕様書とサンプルで、本プロジェクトに必要な項目が揃っていることを検証済みです。購入可否と分析結果の公開条件は問い合わせ中で、詳細は [DATA_SOURCES.md](DATA_SOURCES.md)、[DATA_SCHEMA.md](DATA_SCHEMA.md)、[INQUIRY.md](INQUIRY.md) にあります。

NPB公式サイトの直接取得は行いません。全ページに二次利用と無断転載を禁じる表示があるためです。

## 実行

Python 3.11以上をインストール後、プロジェクトルートで次を実行します。

```powershell
$env:PYTHONPATH = "src"
python -m saikaku.cli samples/decision.json
python -m pytest
```

## 次の実装順

1. ~~プレー単位データを保存する取り込み層~~ 完了（[ingest.py](src/saikaku/ingest.py)）
2. 期待得点、得点確率、勝率をイニング・点差・アウト・走者・球数で推定 ← **データ購入待ち**
3. 左右相性、球種、打球傾向、守備、疲労、連投を特徴量へ追加
4. 観測された采配と、実行可能だった代替案を同一モデルで比較
5. 12球団の試合終了後レポートとX投稿キューを生成

係数を人手で調整して断定的な投稿を作るのではなく、学習期間、データソース、信頼区間、欠損を投稿に明示できる設計へ進めます。試合後すぐの投稿には、速報値と後日確定値を分ける運用が必要です。
