# 采配採点

プロ野球の采配を、結果ではなく意思決定時点の勝利確率の変化で評価するための最小基盤です。

## 評価の考え方

各采配について、次の差分を採点します。

`実際の行動による勝率変化 - 代替案による勝率変化`

プラスならそのケースでは勝利確率を高める方向、マイナスなら代替案を採用した方が有利だった、という意味です。現状のモデル係数は動作確認用のベースラインであり、実運用ではNPBの過去試合データから推定します。

## 実行

Python 3.11以上をインストール後、プロジェクトルートで次を実行します。

```powershell
$env:PYTHONPATH = "src"
python -m saikaku.cli samples/decision.json
python -m pytest
```

## 次の実装順

1. NPBの試合速報・プレー単位データを保存する取り込み層
2. 期待得点、得点確率、勝率をイニング・点差・アウト・走者・球数で推定
3. 左右相性、球種、打球傾向、守備、疲労、連投を特徴量へ追加
4. 観測された采配と、実行可能だった代替案を同一モデルで比較
5. 12球団の試合終了後レポートとX投稿キューを生成

係数を人手で調整して断定的な投稿を作るのではなく、学習期間、データソース、信頼区間、欠損を投稿に明示できる設計へ進めます。試合後すぐの投稿には、速報値と後日確定値を分ける運用が必要です。
