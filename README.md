# 采配採点

プロ野球（NPB）の采配を、結果ではなく**意思決定の時点で勝利確率をどれだけ動かしたか**で評価します。

## 使い方：1試合の采配を採点する

1. `試合/_テンプレート.md` をコピーして、試合ごとにノートを作る（例 `試合/2026-09-27_中日-巨人.md`）
2. 采配の表に、判断の**直前**の場面（回・表裏・アウト・走者・得点）と、采配・打者・投手を書く。選手の力・左右・対戦成績はわかる範囲で
3. `python -m saikaku.game "試合/2026-09-27_中日-巨人.md"` を実行すると、隣に `〜_採点.md` と、X投稿用の画像 `〜_1.png`・本文 `〜_投稿文.txt` ができる（画像には Pillow が必要：`python -m pip install pillow`）

投稿の書式は [POST_FORMAT.md](POST_FORMAT.md) で決めている。

点数は判断ごとの勝率差（pt）の合計です。+1.0pt は、その試合の采配で勝つ確率を合計1%上げたという意味です。結果（成功・失敗）は点数に入りません。

やらなかった判断も采配です。強攻（バントせず）・二盗せず・三盗せず・勝負（敬遠せず）・代打なし・続投も、同じ物差しで採点します。

記入例と出力例は [samples/game.md](samples/game.md) と [samples/game_採点.md](samples/game_採点.md)（架空の試合）。

## 評価の考え方

`実際に選んだ作戦による勝率変化 − 代替案による勝率変化`

プラスなら、その場面では選んだ作戦のほうが勝利確率を高める方向だった、という意味です。

## 勝率モデル

半イニングを「走者×アウト」の24状態を移るマルコフ連鎖とみなし、状態ごとの残り得点分布を実データから推定します（[runs.py](src/saikaku/runs.py)）。その分布とNPBのルールを組み合わせて、試合終了までを計算します（[model.py](src/saikaku/model.py)）。NPBのルールとは、9回裏はホームがリードしていれば行わない、サヨナラで終了、12回終了で同点なら引き分け、の3点です。

- 勝率の土台は両チームをリーグ平均として扱います。采配の評価では、いまの打者から3人目までと投手の力を反映します（下記）
- 引き分けは勝ち0.5として評価します（NPBの勝率計算は引き分けを除くため）
- 得点分布はMLB（Retrosheet）のデータから推定しており、NPBの得点環境との差は未補正です。詳細は [DATA_SOURCES.md](DATA_SOURCES.md) を参照してください

## 采配の評価

選んだ作戦と代替案それぞれについて、直後の場面の分布から期待勝率を出して比べます（[tactics.py](src/saikaku/tactics.py)）。実際の結果は評価に使いません。

| 采配 | 選んだ作戦 | 代替案 |
| --- | --- | --- |
| 送りバント | バントを試みた打席の結果（バント安打・失敗を含む） | 通常打撃 |
| 二盗・三盗 | 単独の盗塁企図の結果 | 自重（その場面のまま） |
| 敬遠 | 打者が一塁へ、押し出される走者だけ進む | 勝負（通常打撃） |

| 代打 | 代打の打者が打つ | そのまま（元の打者） |
| 継投 | 交代した投手が投げる | 続投 |

観測が50件未満の場面は推定しません。

## 打者・投手の力

打席の結果を三振・四球（死球を含み敬遠を除く）・単打・二塁打・三塁打・本塁打・凡打の7つに分け、それぞれが起きたときに走者とアウトがどう変わるかをデータから推定しています（[events.py](src/saikaku/events.py)）。打者と投手の力は7つの起こりやすさのリーグ平均との比で表し、両者の比を掛けて打席の結果を補正します（log5法）。いまの打者から3人目までをこの方法で順に計算し、その先は平均として扱います。

選手の力は次のどちらかで指定します（[abilities.py](src/saikaku/abilities.py)）。

- **型**：MLBの規定打席級の選手を力量順に並べ、上位10%・10〜30%・中位・下位10〜30%・下位10%の層ごとに平均した比。打者は「強打者（上位10%）」から「非力（下位10%）」まで、投手は「エース級（上位10%）」から「不安定（下位10%）」まで
- **成績の手入力**：打者は打席・安打・二塁打・三塁打・本塁打・四球・死球・三振、投手は打者・被安打・被本塁打・与四球・与死球・奪三振。打席数が少ないほどリーグ平均に寄せて見積もります

入力した成績は「リーグ平均の成績」と比べて比にします。NPBの選手を入れるときは、同じ年のNPBリーグ合計も入れると正確です（未入力ならMLB平均と比べます）。**成績の数字はあなたが入力するもので、このツールが取得することはありません。**

## 相性（左右と対戦成績）

- **左右**：打者と投手が同じ側か逆かで、7つの結果の起こりやすさを補正します。逆のほうが打者に有利で、本塁打・四球が増え三振が減ります（MLB 2022〜24年で推定）
- **打者×投手の対戦成績**：手入力した対戦成績を、二人の力と左右から予想される結果と比べ、過去のデータで効くと確かめられた分だけ反映します。効き具合は「2022〜23年の対戦成績で2024年の同じ組み合わせの対戦を最もよく当てる寄せの強さ」で決めています

| 結果 | 寄せ（打席） | 20打席の対戦成績の重み |
| --- | --- | --- |
| 三振 | 約100 | 約16% |
| 四球 | 約170 | 約11% |
| 本塁打 | 約850 | 約2% |
| 安打 | 約1,100 | 約2% |

相性は三振と四球には見られますが、本塁打と安打にはほとんど見られません。対戦打率が高い・低いという記録は、評価をほぼ動かしません。

## 試合経過と当日の調子

試合ノートに「試合経過」（打席ごとの結果）を書くと、

- 判断より前のその日の成績を、選手の力に少しだけ反映します（当日の調子）
- 投手の打者数を自動で数えます
- 「成績の時点: 試合後」なら、選手表のシーズン成績からこの試合の分を差し引き、試合開始時点の成績にします（後知恵を防ぐ）

過去の試合を後から採点するときは、スポーツナビの選手ページの月別成績を使います。その試合の月の末日までの合計を選手表に書き、月末までにまだ試合が残っていれば、その試合の分も差し引きます（2026-08-30 の試合は両チームとも8月最後の試合だったので、8月までの合計から試合経過を差し引くだけで済んだ）。月別成績には敬遠の列がないので、敬遠は0として扱います。

当日の調子がどれだけ次の打席を当てるかは、MLB 2022〜24年で「同じ試合の前の打席から後の打席を予測する」ことで測りました。シーズン成績と打順の巡目を入れた後では、ほぼ何も足しません（投手の被安打で約640打席分の寄せ、他はほぼゼロ）。「今日は当たっている」は、判断の材料としてはごく弱いということです。

## 勝率の推移（プレーごと）

試合経過の各行に、そのプレー後のアウト・走者・得点を書くと、プレーのたびに（打席の途中の盗塁や暴投も含めて）勝率を計算し、レポートに次を出します。

- 勝率の推移グラフ（`〜_勝率.png`。中日が出ている試合は中日の勝率。属性「視点」で変えられる）。采配の判断の位置に印（中日は塗りつぶし、相手は白抜き、色は好判断・互角・疑問）
- 試合の山場：勝率を大きく動かしたプレー5つ
- 勝率を動かした選手：打者（走者）と投手ごとの寄与の合計（WPA）

ここでの勝率は、プレーそのものの価値を測るため、両チームを平均的な戦力として計算しています（采配の採点は選手の力を入れて計算）。

## 投手に代打を出すとき

投手に代打を出すと、次の回は別の投手が投げます。試合ノートに「次の投手」と「降板投手の打者数」を書くと、代打の損得に「次の回を続投した場合と代わった投手の場合の差」を足します（相手の打者は平均として計算）。疲れた先発を代える代打は得が増え、好投中の投手を代える代打は得が減ります。

## 盗塁の成功率

盗塁の結果の分布はMLBの実例から取っていますが、MLBは2023年のルール変更（ベース拡大・牽制制限）で成功率が上がっており、2022〜24年で約78%です。試合ノートの「リーグ平均」に盗塁・盗塁刺を書くと、成功のオッズをそのリーグの成功率に合わせます（2026年のセ・リーグは71.2%）。

さらに「走者名」と、その選手の盗塁・盗塁刺を書くと、走者本人の成功率も使います。ただし本人の成功率はリーグ平均に強く寄せます。前年までの成績で翌年を最もよく当てたのは、約180回分のリーグ平均を足したときでした（MLB 2022〜24年）。成功率の個人差は、見た目の数字ほどは翌年に続かないということです。

## 投手の疲れ（打順の巡目）

同じ投手でも、打順が一巡するごとに打たれやすくなります。MLB 2022〜24年で、投手自身の実力から予想される結果と比べて測った補正をかけています。

| 打者との対戦 | 三振 | 二塁打 | 本塁打 |
| --- | --- | --- | --- |
| 1巡目 | +4% | -4% | -7% |
| 2巡目 | -5% | +4% | +4% |
| 3巡目以降 | -9% | +8% | +11% |

試合ノートの「投手の打者数」（その場面までに投手が対戦した打者の数）を書いた場面だけ反映します。継投で出てくる投手は投げ始めとして扱うので、3巡目の先発を代える継投は、同じ実力の投手どうしでも得になります。中継ぎどうしの継投の損得は、投手の成績を入れないと出ません。

走者の足の速さと守備は反映していません。

## 実行

Python 3.11以上が必要です。

```powershell
# 得点分布を作る（初回とデータ更新時）。zipは %LOCALAPPDATA%\Saikaku\retrosheet に置く
$env:PYTHONPATH = "src"
python -m saikaku.fit "$env:LOCALAPPDATA\Saikaku\retrosheet\2024plays.zip"

# 采配を1件採点する（選手・左右・対戦成績の指定方法は src/saikaku/cli.py の先頭を参照）
python -m saikaku.cli samples/decision.json

# デモ画面を作る（demo/index.html。ブラウザで直接開ける）
python -m saikaku.demo

python -m pytest
```
